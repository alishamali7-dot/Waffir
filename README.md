# مُوَفِّر · Mwaffir

تطبيق ميزانية شخصية بالعربية والإنجليزية، موجَّه لمتجر Google Play.
React Native + Expo، وقاعدة Supabase للمزامنة الاختيارية.

A bilingual personal budgeting app for Google Play. React Native + Expo,
with an optional Supabase sync layer.

---

## القرارات التي تحكم المشروع

هذه ليست تفاصيل تنفيذ، بل قيود تسبق الكود. من يعدّل هنا يقرأها أولًا.

### ١. إدخال يدويّ بحت — لا ربط بأيّ جهة

لا Apple Pay، ولا Google Pay، ولا Samsung Pay، ولا أيّ بنك، ولا قراءة
إشعارات، ولا استيراد ملفات. قرار المالك، واتُّخذ بعد بحث موثّق في
[`INTEGRATION.md`](INTEGRATION.md) خلص إلى أن محافظ أنظمة التشغيل مغلقة
بالتصميم وأن المصرفيّة المفتوحة في الكويت ما زالت مسوّدة.

التطبيق أونلاين: حساب ومزامنة بين الأجهزة. و«offline-first» هنا تحمّلُ
انقطاع لا استقلالٌ عن الإنترنت — الكاش المحلّي يُبقيه يعمل حين يسوء
الاتصال، لا حين لا يوجد حساب.

### ٢. لا شيء مخصّص لمستخدم بعينه

الفئات والحدود والعملة والدخل كلّها من إعداد المستخدم أو من بذرة في
[`templates.ts`](templates.ts). لا رقم ولا اسم في منطق التطبيق. العملة
تُختار في أوّل تشغيل، وليست د.ك افتراضًا لا يُغيَّر.

### ٣. المال أعداد صحيحة بأصغر وحدة

`1234.567 د.ك` تُخزَّن `1234567`. لا `float` ولا `numeric`. عدد الخانات
من `minor_units` في ملفّ المستخدم: ٣ للدينار، ٢ لأغلب العملات، ٠ لليَن.

### ٤. المزامنة offline-first

الجهاز هو مصدر الحقيقة، و Supabase نسخة ومزامنة. المعرّفات `uuid`
يولّدها الجهاز، والحذف `deleted_at` لا `DELETE`، والمؤشّر من ساعة
السيرفر لا من ساعة الجوال. التفاصيل في
[`supabase/README.md`](supabase/README.md).

### ٥. فصحى ميسّرة لا عاميّة

«وش» و«شلون» و«وين» تُفهم في الخليج وحده، والتطبيق يقرأه مصريّ ومغربيّ
وسوريّ. وفيه وحدة مستقلّة للعدد والمعدود لأن «٢ حسابات» خطأ والصواب
«حسابان». السياسة والتفاصيل في [`i18n/ar.ts`](i18n/ar.ts).

## الاختبارات

بلا أيّ مكتبة اختبار — `node --test` وحده.

```bash
npx tsx --test quickEntry.test.ts i18n/i18n.test.ts sync/plan.test.ts sync/sync.test.ts
```

```bash
npx tsc --noEmit --strict --skipLibCheck --target es2020 --moduleResolution bundler --module esnext types.ts budget.ts quickEntry.ts templates.ts supabase/database.types.ts
```

واختبارات تعمل على قاعدة Supabase الحقيقية داخل معاملة تُلغى — نتائجها
في [`supabase/README.md`](supabase/README.md).

## الإعداد

```bash
cp .env.example .env.local
```

ثم ضَع رابط مشروعك ومفتاحه `publishable`. بدونهما يعمل التطبيق كاملًا
مع تعطيل المزامنة وحدها.
